# YardVision

AI-powered Yard Management and Gate Automation System.

## Goal

YardVision explores automated vehicle processing at logistics yard gates using
computer vision, OCR, backend services, and event-driven workflows.

## Planned Architecture

- Python AI Service
- OpenCV
- PyTorch / YOLO
- OCR
- FastAPI
- Ruby on Rails
- PostgreSQL
- React + TypeScript
- Docker
